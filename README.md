# 🎓 升中面試規劃 | HK Secondary School Admission Planner

為香港家長打造的升中面試規劃平台，覆蓋 **2026-2027 升中年度**（P5 → S1）。

## ✨ 功能

- 🏫 **33 間頂尖中學資料庫**：聖保羅男女、拔萃男書院、拔萃女書院、皇仁書院、喇沙書院等
- 📊 **排名與篩選**：按類型（直資/私立/官津）、性別、地區篩選
- 📅 **互動月曆**：所有報名截止、面試日期一目了然
- 🗓️ **完整時間線**：從 10 月開放到 7 月派位結果
- 📌 **申請追蹤**：記錄已報名/已面試/獲取錄狀態（瀏覽器本地儲存）

## 🚀 本地開發

```bash
npm install
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000)

## 🌐 部署

部署到 GitHub Pages：push 到 `main` 分支即可自動部署。

網站：https://openclawruby.github.io/School/

## 📁 資料來源

學校資料儲存於 `data/schools.json`，可以手動更新後 push。

## ⚠️ 免責聲明

所有資料僅供參考，實際報名、面試、收生準則以學校官方公布為準。
